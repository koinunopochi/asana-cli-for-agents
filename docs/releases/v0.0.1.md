# v0.0.1

Initial public release of `asana-cli-for-agents`.

## Included

- Environment-based authentication with `ASANA_ACCESS_TOKEN`.
- JSON output for bounded workspace, project, section, user, and task reads.
- Task search with common workspace filters.
- Explicit `--confirm` boundary for task mutations.
- Cross-platform release archives for Linux, macOS, and Windows on amd64 and
  arm64.

The CLI intentionally has no task deletion command in this release.
