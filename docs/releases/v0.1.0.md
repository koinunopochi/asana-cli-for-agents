# v0.1.0

Adds project structure commands to `asana-cli-for-agents`.

## Added

- `project create` creates a project. `--team` is required when the workspace
  is an organization.
- `section create` adds a section, which is a column in board view.
- `project add-field` adds an existing custom field (`--field`) or creates a new
  one (`--field-json`) on a project, which is a column in list view.
- `team list`, `field list`, and `project fields` look up the team, custom
  field, and custom field setting GIDs that the new write commands need.

Every new write command requires `--confirm`. This release has no project,
section, or custom field deletion command.
